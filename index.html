Scope

Calculators implement standard textbook relations: exponential decay, Poisson counting statistics, simplified MDA, ideal mixing, first-order compartment models and approximate attenuation data. Nuclide data and coefficients are approximations intended for education, coursework and screening. They are not certified dosimetry or regulatory reporting.

FORMULAS · CONSTANTS · NUCLIDES

Core formulas

Decay law

A(t) = A₀ · 2^(−t/T½)

Activity

A = λN, λ = ln2 / T½

Counting

R = N / t, u(N) ≈ √N

Efficiency

ε = R / (A · p)

Activity concentration

C = N / (t · ε · p · m)

MDA (simplified)

MDA ≈ k·√N_b / (t · ε · p · m)

Attenuation

I = I₀ e^(−μx), HVL = ln2/μ

Distribution coefficient

Kd = C_solid / C_water

Soil inventory

I = C · ρ_b · d

Riverine flux

F = C · Q

Intake

I = C · consumption · time

Bateman chain

Nᵢ = Σⱼ e^(−λⱼt) Π λₖ/(λₖ−λⱼ)
